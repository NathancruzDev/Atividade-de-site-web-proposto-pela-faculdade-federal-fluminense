# Trabalho Acadêmico

Projeto de desenvolvimento de sistemas proposto pela Universidade Federal Fluminense (UFF).

## Objetivo do Trabalho
Com base nos módulos iniciais do curso, obtivemos experiência em sistemas atualmente considerados legados. Assim, foi proposto o desenvolvimento de um site utilizando apenas **HTML** e **CSS**, sendo a primeira parte composta por códigos no formato de tabelas — recurso bastante utilizado em versões anteriores aos padrões do **HTML5**.

## Ferramentas Utilizadas
- Linguagem de marcação **HTML**  
- **CSS**
